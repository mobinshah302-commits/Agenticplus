# 🤖 ایجنت شخصی تلگرام (Personal AI Agent Bot)

ربات تلگرامی که هر کاربر با API خودش (هر پرووایدری: OpenAI, Anthropic/Claude, Gemini,
OpenRouter, Groq, DeepSeek, Mistral, xAI, Together, یا هر API سفارشی سازگار با OpenAI)
یک ایجنت شخصی می‌سازه. ایجنت می‌تونه:

- 💬 چت حرفه‌ای چندنوبتی با تاریخچه‌ی جدا برای هر مکالمه
- 🖥 کد بنویسه و **اجرا** کنه (پایتون / جاوااسکریپت / بش) داخل محیط شخصیِ خودِ کاربر روی سرور
- 📦 پکیج نصب کنه (pip / npm) داخل همون محیط شخصی، بدون محدودیت مصنوعی
- 🔎 وب‌سرچ واقعی انجام بده (بدون نیاز به کلید API جدا)
- 🌐 صفحات وب رو باز کنه و بخونه
- 🎨 تصویر بسازه (اگه کاربر یک API تصویر مثل DALL·E / Stability / Replicate وصل کرده باشه)
- 🎬 ویدیو بسازه (از طریق Replicate)
- ⚙️ تنظیمات کامل: دما، سقف توکن روزانه/ماهانه، تایم‌اوت اجرای کد، روشن/خاموش کردن هرکدوم از ابزارها

## ⚠️ نکته‌ی مهم امنیتی درباره‌ی Sandbox

روی Railway امکان اجرای Docker-in-Docker (یک container جدا برای هر کاربر) وجود نداره،
چون خودِ Railway هم یک container غیرممتازه. به‌جاش این پروژه برای هر کاربر تلگرام یک
**یوزر لینوکسی جدا** (بدون sudo/root) با هوم دایرکتوری اختصاصی می‌سازه و کدها رو با
آن یوزر اجرا می‌کنه. این یعنی:
- کاربرها فایل همدیگه رو نمی‌بینن (پرمیشن سطح فایل‌سیستم)
- هرکسی می‌تونه هر زبون/پکیجی که بخواد داخل هوم خودش نصب و اجرا کنه
- ولی ایزولاسیون شبکه/کرنل مثل Docker واقعی نیست — اگه پروژه بزرگ شد و ترافیک/ریسک بالا رفت،
  توصیه می‌شه به یک VPS با Docker واقعی (یک container کاملا جدا به‌ازای هر کاربر) مهاجرت کنید.

## 🚀 راه‌اندازی

### ۱) گرفتن توکن ربات
از [@BotFather](https://t.me/BotFather) در تلگرام یک ربات بساز و توکنش رو بگیر.

### ۲) دیپلوی روی Railway
1. این پروژه رو به یک ریپازیتوری گیت‌هاب پوش کن.
2. توی Railway یک پروژه‌ی جدید از روی همون ریپو بساز (Deploy from GitHub repo).
3. یک **Volume** به مسیر `/data` وصل کن (برای این‌که دیتابیس و هوم کاربرها بین دیپلوی‌ها پاک نشه).
4. متغیرهای محیطی زیر رو ست کن:
   - `BOT_TOKEN` = توکنی که از BotFather گرفتی
   - `DATA_DIR` = `/data`
   - `FERNET_KEY` (اختیاری، اگه ندی خودش می‌سازه و توی Volume ذخیره می‌کنه)
5. دیپلوی کن. چون Dockerfile هست، Railway خودش می‌سازتش و اجرا می‌کنه.

### ۳) اجرای لوکال (برای تست)
```bash
pip install -r requirements.txt
export BOT_TOKEN=xxxx
export DATA_DIR=./data
python main.py
```
> توجه: بخش sandbox (`useradd`, `su`) نیاز به لینوکس و دسترسی root داره؛ روی مک/ویندوز اجرای کد کار نمی‌کنه (فقط چت/وب‌سرچ کار می‌کنه). برای تست کامل از یک کانتینر لینوکسی یا همون Railway استفاده کن.

## 📂 ساختار پروژه
```
main.py                  # نقطه‌ی شروع
bot/
  config.py               # تنظیمات و مسیرها
  db.py                    # لایه‌ی دیتابیس (SQLite)
  crypto.py                # رمزنگاری کلیدهای API
  providers.py             # پریست پرووایدرهای معروف
  ai_client.py             # لایه‌ی یکپارچه روی OpenAI/Anthropic/Gemini/Replicate/Stability
  sandbox.py               # اجرای کد per-user
  websearch.py             # وب‌سرچ (اسکرپینگ)
  agent.py                 # حلقه‌ی ایجنت (تشخیص و اجرای ابزار)
  keyboards.py / texts.py / states.py
  handlers/                # هندلرهای تلگرام (start, providers, chats, tools, settings, messages)
```

## 🔧 توسعه‌ی بیشتر (پیشنهادها)
- افزودن Playwright برای مرورگر واقعی (رندر جاوااسکریپت) به‌جای فچ ساده‌ی HTML
- افزودن function-calling رسمی برای پرووایدرهایی که پشتیبانی می‌کنن (دقیق‌تر از پارس متنی)
- شمارش دقیق‌تر توکن ورودی برای پرووایدرهایی که usage برنمی‌گردونن (مثل بعضی سازگارهای OpenAI)
- صف‌بندی درخواست‌های ویدیو (چون طولانی هستن) به‌جای بلاک کردن هندلر
